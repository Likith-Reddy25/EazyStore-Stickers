# 🛒 E-Commerce Web Application

Welcome to the **E-Commerce Web Application** 🚀  
A **full-stack online shopping platform** that allows users to browse products, place secure orders, and complete online payments, while enabling admins to efficiently manage products and orders.

---

## ✨ Features

### 👤 User Features
- 🔐 Secure user registration and login using **JWT authentication**
- 🛍️ Browse products with detailed descriptions and pricing
- 🛒 Add, update, and remove items from the shopping cart
- 💳 Secure checkout using **Stripe payment gateway**
- 📦 View order history and order status
- 📱 Fully responsive UI for mobile and desktop devices

### 🧑‍💼 Admin Features
- 🔒 Secure admin access with role-based authorization
- ➕ Add new products to the inventory
- ✏️ Update product details and availability
- ❌ Delete products from the inventory
- 📊 Manage customer orders efficiently

---

## 🧩 Tech Stack

### 🎨 Frontend
- ⚛️ React.js
- 🎨 CSS3
- 🔗 Axios for API communication

### 🛠️ Backend
- 🌱 Spring Boot
- 🔐 Spring Security
- 🪪 JWT (JSON Web Token) authentication
- 🌐 RESTful APIs

### 🗄️ Database
- 🐬 MySQL

### 💳 Payment Gateway
- 💳 Stripe (secure and fully authorized payment processing)

---

## 🔐 Authentication & Security
- 🪪 JWT-based stateless authentication
- 👥 Role-based access control (User / Admin)
- 🔑 Secure API endpoints using Spring Security
- 🛡️ No sensitive payment data stored (handled by Stripe)

##  Installation
1) Backend
# Clone repository
git clone https://github.com/your-username/ecommerce-app.git

# Navigate to backend
cd backend

# Run application
mvn spring-boot:run

2) Frontend
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start React app
npm start
